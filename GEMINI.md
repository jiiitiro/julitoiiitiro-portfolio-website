# Antigravity Guidelines & Memory

## Repository Workflow Rules

1. **Commit & Push Requirements**:
   - Short, lowercase commit messages consistent with existing repository history.
   - No assistant attribution trailers in commits (e.g. no `Co-Authored-By: ...`).
   - Update `README.md` and `HANDOFF.md` before every commit and push.
   - **PR Generation on Push**: Whenever changes are pushed (or prepared for a push/PR), always automatically generate a ready-to-use Pull Request title and comprehensive description formatted in GitHub markdown.

2. **Privacy & Attribution Boundaries**:
   - Phone number belongs strictly on `/resume` and `/resume.pdf`, never on public website pages.
   - For AGREEMO: role is strictly project manager, backend API (Python, Flask, PostgreSQL), and helped assemble hardware. Do not credit with Flutter app or web dashboard. Never publish the AGREEMO manuscript.
   - Sensitive data (phone numbers, balances, third-party emails) must be masked in all screenshots and videos.
